# Image credits and licence status

**Important:** every photo in `public/images/menu/` is a placeholder found on the web while the site was built. The owner's own photos could not be downloaded from the build environment, which can only reach package registries and GitHub. Before launch, replace these with photos of Heritage Bites' own food. If the owner keeps any of these, first confirm the licence at the source page.

**Where to replace:** add the owner's photos to `public/images/menu/` with the same file names (or update the item image list in `lib/seed-data.ts`). The staff console's launch checklist has an item for this.

## Licence categories used below

- **Free licence (Pexels):** Pexels licence. Free for commercial use; confirm on the source page.
- **Free licence (Unsplash):** Unsplash licence. The source image is hosted on `images.unsplash.com`; confirm on the source page.
- **Stock agency or free-photo site:** Adobe Stock, Vecteezy or Dreamstime. Licence terms vary by file (some free with attribution, some paid). Confirm before any commercial use.
- **Editorial or recipe-site photo:** copyright held by the publisher or photographer. Not licensed for this business. Replace before launch.
- **Pinterest pin:** the image belongs to the original publisher. Not licensed for this business. Replace before launch.
